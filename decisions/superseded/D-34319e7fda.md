## 结论
v0.45 keeps rejected route checks blocked by default, supports explicit ALLOWED_WITH_REOPEN only for matching rejected decisions with reopen_condition and --reopen-reason, and also permits an exact config duplicate only when that duplicate run is failed/aborted and is evidence for the explicitly reopened decision. It records reopened_decision_ids_json and reopen_reason in route_checks. Verified by full unittest suite.
